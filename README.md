# Rihlah

A private, offline, installable personal tracker. Four tabs: Gym, Qur'an, Sabr, and a 24-hour log.

## Privacy

All data is stored in the browser's local storage on your device only. This repository and GitHub Pages contain the app code only — no data is ever sent anywhere.

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

Expected address: `https://hafizirshaadi.github.io/rihlah-app/`

## Install on iPhone

Open the published address in Safari, tap **Share**, choose **Add to Home Screen**, then **Add**. Open it once while online so offline files are cached.
